## 参考图事实（已从图片逐点核实）

- 深色模式倒班 App，2026 年 10 月，今天 = 23 日；顶部「日历/统计」二级 tab，底部「首页/日历/闹钟/设置」
- 格子内容 = 日期数字（顶）+ 可选彩色小标签（「国庆」红 /「调休/补班」橙）+ **2~3 个纵向堆叠的实心胶囊**
- 胶囊内文字 = **时间段**，**全图无任何班次名称**
- 胶囊 = **实心填充 + 白字**，圆角 8~10px、**宽度撑满格子**，高约占格宽 1/3
- **颜色编码是到班次粒度的，不是按天**：`灰 = 该班次已过期`、`蓝 = 未结束`。证据：今天（23 日）上两个胶囊灰（`0-2`、`10-12` 已过去）、最下 `20-22` 蓝（进行中）；24~29 日全蓝；1~22 日全灰
- **日期数字本身也会变色**：今天那个数字是蓝色加粗，其他日子白字
- 今天额外套一层**深蓝色圆角矩形框，盖住整个格子**（含内边距），圆角比胶囊更大
- **行内不等高**：每行格子的顶部对齐线一致，但每个格子按内容（胶囊数）单独撑高，底部不对齐
- **无农历**；未排班的日子（30、31 日）整格只留日期数字
- 顶部图例：🔴节假日 🟠调休上班；右上「今日」按钮
- ⚠️ 30、31 日空白 + 23~29 日胶囊数变少，可能只是那个 App 自己的班表排到 29 日断了，不必效仿

## 现状事实（已从 `calendar_screen.dart` 核实）

- 格子现为**三行**：日期 / 班次（胶囊或倒计时）/ 农历
- **根因**：第 2 行只画「首末时段」（如 `6:00-18:00`）或「岗次数」——**一天 3 个时段只显示首末，中间那个看不到**。这就是「可读性」问题的根源
- 「已调班」 = 右上角小圆点（挂在胶囊上时胶囊已删）；「今天」格第 2 行只显示倒计时、不显示时段
- 网格已支持「内容超时可滚、格子保持全尺寸」——对新布局是好消息，不用为塞内容牺牲尺寸
- `calendar_screen.dart` 共 2262 行，格子渲染在 1710~2160 行附近

## 改动清单（0.14.0）

1. **格子重写**（`calendar_screen.dart`）：日期 + 节假日/调休小标签 + 时段胶囊 ×N；去掉农历/倒计时/首末时段；保留「已调班」小点与「今天」选中框；**行内等高 + 内容自适应**（每行高度由该行最多胶囊数决定，坐标换算从均分 `cellH` 改为**行高累加**）
2. **时段胶囊**：实心班次色 + 白字 + 时间段（`6-8` / `22-0` 无冒号），深浅/饱和度编码时间远近（已过期 / 进行中 / 未结束），宽度撑满格子
3. **新增「今日信息卡」**（0.13.0 删了，现在恢复 + 内容扩展）：今天日期 + 班次列表（名 + 时间 + 颜色点）+ 农历 + 倒计时 + 已调班 + 节假日 + 本月统计；复用 `info_card_metrics.dart` 的高度测算
4. **版本号**：0.14.0+182（X.Y 用户定，我只改 Z）
5. **导航栏**：不改（#12）

## 最终格子布局

```
┌─────────────┐
│  23  ●已调班  │  ← 日期数字（今天蓝加粗）+ 右上角「已调班」小点
│  国庆        │  ← 节假日/调休小标签（红/橙，可选）
│  ████████   │  ← 时段胶囊 ×N（实心班次色 + 白字 + 时间段）
│  ████████   │     深浅/饱和度编码时间远近

     ↑ 今天额外套深色圆角框盖住整个格子
```
